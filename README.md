# Peter Richards — Personal Website

Source code for my personal website, built with Quarto and deployed via GitHub Pages.

**Live site:** https://peterrichardsutep.github.io

## Built with

- [Quarto](https://quarto.org)
- GitHub Pages

## Structure

- `index.qmd` — home page (CV, research interests, skills, and contact)
- `project.qmd` — ECON 5371 research project page
- `files/` — downloadable CV
- `images/` — headshot and favicon
- `docs/` — rendered site published by GitHub Pages (do not edit directly)
